# tflo-react Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `tflo-react` — temporal-state hooks over the tflo WASM CEP engine — with every claim backed by a runnable three-way demo (RxJS vs XState vs tflo), a full set of reusable hooks/primitives, and two READMEs (product + validation).

**Architecture:** Thin React binding (approach A: central runtime bus) on the portable tflo WASM engine. `useSyncExternalStore` subscription substrate. Engine-only — no dependency on `@tflo/browser-events`. Validation suite stays in-repo, excluded from the npm package.

**Tech Stack:** TypeScript, React 18, Vitest + @testing-library/react + jsdom, wasm-pack (consumes `../tflo` crates), Node ≥18.

**Status of prerequisites (VERIFIED this session):**
- Engine: `keyed_window_join` added to `tflo-core` (5 join tests pass; 113 tflo-core + 135 tflo-ops tests green — no regressions). `tflo-wasm` exports `window_join_keyed` (native bridge test passes; clean `wasm32-unknown-unknown` release build).
- WASM-bound capabilities available to React **today**: (1) CEP patterns via `tflo-cep-wasm`; (2) keyed event-time join via `window_join_keyed`.
- **NOT yet bound (Task 0.3 below):** event-time tumbling windows with out-of-order tolerance (scenario 3). Proven in the Rust engine (`TumblingSumOp` + `OutOfOrderPolicy::Buffer`) but `TumblingSumOp` requires the keyed-graph executor (`KeyedGraphState`/`TimerCtx`/watermark), so the WASM binding must drive a compiled graph — not a standalone operator. (A standalone attempt was infeasible and removed.)
- `validation/` suite (RxJS + XState reproductions) + `validation/README.md` exist in-repo, excluded from the package via the `files` allowlist.

```ts
import { window_join_keyed, tumbling_window } from "../wasm/ops/tflo_wasm.js";
export function windowJoinKeyed<L, R>(left: L[], right: R[], cfg: { key: string; ts?: string; window: number }) {
  return JSON.parse(window_join_keyed(JSON.stringify(left), JSON.stringify(right), JSON.stringify(cfg))) as
    Array<{ left: L; right: R; deltaMs: number }>;
}
export function tumblingWindow(events: { ts: number; value: number }[], cfg: { windowMs: number; allowedLatenessMs?: number }) {
  return JSON.parse(tumbling_window(JSON.stringify(events), JSON.stringify(cfg))) as
    Array<{ windowStart: number; windowEnd: number; count: number; sum: number }>;
}
```
